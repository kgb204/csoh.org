ATT&CK Coverage Heatmap

Which MITRE ATT&CK techniques actually show up across CSOH's breach kill chains - built live from the same pages, not a fixed sample.

Every cell below is aggregated at page load from /data/chains-index.json and the per-chain files it lists - one JSON file per kill chain on the breach timeline. Add a new kill chain page and re-run tools/build_attack_heatmap_data.py, and its techniques appear here automatically; nothing on this page hardcodes a technique or chain name. Steps whose breach page didn't tag an explicit MITRE technique are left out rather than guessed - see the 🚩 marker below for the technique-tactic pairs that were inferred (a technique valid under more than one ATT&CK tactic, placed using the page's own kill-chain phase) and could use a human check.
