Blast Radius Visualizer

Every breach in our kill chain library as an interactive attack-path graph. Pick any asset and run a breadth-first search from it — the graph lights up everything an attacker reaches downstream, coloured by hop distance. That spread is the asset's blast radius. Each edge is a real MITRE ATT&CK technique.

How to read it: Nodes are assets (identities, credentials, services, data). Directed edges show how compromise propagates. Click or tab to any node to make it the origin — reachable nodes recolour by how many hops away they are, and unreachable ones fade out. Hover an edge to see the ATT&CK technique. Arrive here from a kill chain page and that breach is pre-selected.

    Why this matters. A single leaked credential is rarely the whole story — what makes a breach catastrophic is everything downstream of it. Modelling that spread is exactly how defenders reason about least privilege and segmentation: shrink the blast radius so one compromised node can't reach the crown jewels. Practice these paths in the cloud security CTFs, or read the full write-ups in the breach kill chains.

    Want to add a scenario? Drop a JSON file in /data/chains/ and add it to chains-index.json — the visualizer picks it up automatically. See the schema in data/chains/README.md.
